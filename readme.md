
# Sistema de Gestión de Cafetería y Repostería

Proyecto final de Bases de Datos II.

## Tecnologías
- Python
- Flask
- MongoDB Atlas
- HTML y Bootstrap

## Historias de usuario
- HU-01: Gestionar categorías
- HU-02: Gestionar productos
- HU-03: Gestionar clientes
- HU-04: Gestionar empleados
- HU-05: Gestionar ventas

## Ejecución
1. Crear y activar el entorno virtual.
2. Instalar las dependencias (python -m pip install Flask pymongo certifi python-dotenv)
3. Ejecutar python app.py.
